# Citing JAXTPC

If you use JAXTPC in your research, please cite it.

!!! note "The authoritative source is `CITATION.cff`"
    The machine-readable [`CITATION.cff`](https://github.com/DeepLearnPhysics/JAXTPC/blob/main/CITATION.cff)
    at the repository root is the source of truth. On GitHub, use the **"Cite this
    repository"** button (top-right of the repo page) to get an auto-generated
    APA/BibTeX entry that always tracks the current metadata. The text below is a
    human-readable rendering of that file.

## Citation

> Alterkait, Omar. *JAXTPC: GPU-accelerated, differentiable liquid-argon TPC
> detector simulation in JAX* (Version 0.9.0) [Computer software].
> Tufts University. https://github.com/DeepLearnPhysics/JAXTPC
